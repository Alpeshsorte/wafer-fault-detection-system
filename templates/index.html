Help & Documentation
How to Use the System:
  1. Upload CSV File: Go to "Upload & Analyze" and select your wafer data CSV file
  2. File Format: CSV with sensor columns named according to our engineering convention
  3. Analysis: The system will automatically process and predict fault status
  4. Results: View predictions, download results, and analyze fault patterns
Supported File Format:
  • CSV files with wafer sensor data
  • First column: Wafer IDs
  • Subsequent columns: Sensor readings (TEMP_, PRESS_, FLOW_, etc.)
  • Maximum file size: 16MB
Model Information:
  • XGBoost: 97.49% accuracy (primary model)
  • Random Forest: 94.72% accuracy (secondary model)
  • Consensus: Combined prediction from both models
